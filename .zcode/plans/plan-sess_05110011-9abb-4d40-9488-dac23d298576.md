## 第 7 轮审计修复计划

### 架构事实（已核实）
- **admin/app gRPC 服务器注册 0 个业务服务**（仅 DTM workflow），非客户端直接攻击面。
- **core gRPC 注册 37 个业务服务**，是 BFF gRPC 调用的目标；直连无 metadata → SystemViewer → 全租户。
- **中间件链顺序 bug**：`ent.Server()` 在 `auth.Server()` **之前**执行（ms[2] vs ms[3]），导致 BFF REST 即使非白名单请求也总以 md==nil 到达 ent.Server → 总注入 SystemViewer。`md!=nil` 分支（ent.go:57）对 REST 实际是死代码。UserViewer 仅在 BFF→core gRPC 传播（gRPC metadata header）时有效。
- **公开 app 内容路由**（14 个 List/Get 白名单）当前跨租户返回已发布内容，无 host→租户解析中间件。这是产品级设计决策，本轮不引入 host 解析（范围过大）。

### 修复项（按优先级）

**R7-C2: ent.Server() 顺序修复 + fail-closed 收紧**
